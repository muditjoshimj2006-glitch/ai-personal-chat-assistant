# AI Personal Chat Assistant 🤖

An AI-powered personal chat assistant built with **Python** and the **Google Gemini API**. The assistant can hold conversations, remember recent messages during the session, generate a conversation summary, and save chat history to a text file.

---

## Features

* 💬 Interactive AI chatbot
* 🧠 Conversation memory using chat history
* 📄 Automatic conversation summary
* 💾 Save chat history to a text file
* 👤 Personalized user interaction
* 🚪 Exit command to end the conversation
* ⚠️ Basic error handling

---

## Technologies Used

* Python
* Google Gemini API
* Python Dotenv
* File Handling
* Lists
* Functions
* Loops
* Exception Handling

---

## Installation

1. Clone this repository.
2. Install the required packages:

```bash
pip install google-genai python-dotenv
```

3. Create a `.env` file.

```env
API_KEY=YOUR_GEMINI_API_KEY
```

4. Run the project:

```bash
python main.py
```

---

## Usage

* Enter your name.
* Start chatting with the AI assistant.
* Type **exit** whenever you want to end the conversation.
* The assistant generates a conversation summary and saves the chat history.
